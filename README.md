# osu! Beatmap Finder

一個可以讓你更快速、更方便尋找 osu! 圖譜的小工具！

![osu-Beatmap-Finder](https://i.pinimg.com/736x/aa/a8/79/aaa87978a66f9e3fc11fb10ed97a93df.jpg)

## 關於程式

<sub>
本程式使用 <b>Python + QML</b> 開發，並透過 <b>Nuitka</b> 編譯及打包為 Windows <code>.exe</code> 執行檔<br>
本程式<b>不包含病毒、木馬或其他惡意程式碼</b><br>
由於 Nuitka 編譯後的執行檔結構與一般程式不同，加上目前沒有購買 Code Signing Certificate，部分防毒軟體或 VirusTotal 引擎可能會將程式誤判為 <code>Unsafe</code>、<code>Malicious</code> 或其他風險項目<br>
這屬於 <b>False Positive（誤判）</b>，並不代表程式本身具有惡意行為<br>
Windows SmartScreen 顯示 <b>未知的發行者</b> 也是因為目前沒有受信任的數位簽章，並不是因為程式含有病毒
</sub>
